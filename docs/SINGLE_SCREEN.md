# 단일 화면 현장 사용

1. Vercel에서 수정한 소스를 배포합니다. 기존 `VITE_SUPABASE_URL`과 `VITE_SUPABASE_ANON_KEY`는 유지합니다. 처음 한 번 `/host`에 로그인해 행사를 만들고 여섯 자리 코드를 확인합니다. 이후 같은 행사를 재사용하며 `행사 종료` 조작은 없습니다.
2. 고정된 `/vote/행사코드` 주소를 연수 슬라이드의 버튼에 연결합니다. 선택적으로 Vercel의 `VITE_EVENT_CODE`에 여섯 자리 코드를 등록하고 다시 배포하면 `/vote`도 같은 방을 가리킵니다. QR도 매번 같습니다. 새 회차가 필요할 때만 `투표 초기화`를 누릅니다.
3. 노트북에서 `/screen/행사코드`로 들어갑니다. 동일 브라우저에 강사 로그인이 유지되면 하단 조작판이 나타납니다. 다른 브라우저라면 오른쪽 위 `강사 로그인`을 사용합니다. 전체 화면은 새 탭에서 열립니다. 하단 `관리자` 버튼으로 같은 행사 운영 화면에 돌아갈 수 있고 `첫 화면` 버튼도 있습니다. 여기서 투표 시작·마감·단계 이동·동점 선택·음성 테스트·초기화를 모두 조작합니다. 화면을 프로젝터로 복제해도 됩니다.
4. 청중은 투표 완료 뒤 강사의 마지막 화면까지 기다립니다. 마지막 화면에서 `원래 자료로 돌아가기`를 누르면 `https://japanslide.vercel.app/read/day1#slide-3`으로 돌아갑니다. 강사 화면의 버튼은 `https://japanslide.vercel.app/present/day1`로 이동하며 이전 발표 위치는 같은 탭의 세션 저장 상태에 따릅니다.

## 노트북 한국어 → 일본어 음성 테스트

1. 실제 강의에 쓸 Windows 노트북의 Chrome 또는 Edge로 강사 로그인 후 `/screen/행사코드`를 엽니다.
2. Windows 설정에서 한국어와 일본어 음성 합성이 각각 설치되어 있는지 확인합니다. 노트북 스피커 또는 HDMI 출력 장치를 먼저 선택하고 음량을 올립니다.
3. 하단 `음성 켜기`를 클릭합니다. 한국어 인사 후 일본어 인사가 이어지는지 들으세요. 음성 상태에 한국어와 일본어 음성 이름, `로컬` 표시가 둘 다 나오는지 확인합니다. `오프라인 확인 필요`라면 해당 음성은 네트워크에 의존할 수 있습니다.
4. 데모 `/screen/DEMO`에서 다음 → 투표 시작 → 가상 표 추가(`/host?demo=1`에서) → 마감 → 1위 발표 → 프롬프트 공개 → AI에게 요청 순으로 진행합니다. 한마디는 한국어 다음 일본어로 읽은 후 약 3.5초 뒤 결과물로 넘어갑니다.
5. Wi-Fi를 끊은 뒤 이미 캐시한 데모에서 다시 `음성 켜기`와 한국어·일본어 재생을 확인합니다. 강의실 프로젝터 연결 직후에도 출력 장치를 다시 확인합니다. 오프라인 테스트는 음성에 한정되며 실제 투표는 인터넷이 필요합니다.

브라우저에 해당 언어의 음성이 없으면 자막은 계속 표시됩니다. 실제 음질과 오프라인 작동은 같은 노트북과 브라우저로 확인해야 합니다. 일본에서도 노트북·브라우저·설치된 로컬 음성을 그대로 쓰면 음성은 현지 네트워크와 무관하게 재생할 수 있습니다.

## 자료 확인 및 교체

관리자 상단 `자료 확인` 또는 `/materials`에서 항목별 대표 자료 6개를 확인합니다. 이전·다음 부분 버튼으로 모든 내용을 볼 수 있습니다. 다운로드는 완성된 단일 HTML 형식이며, 더블클릭해 브라우저에서 열고 인쇄 메뉴에서 PDF로 저장할 수 있습니다. 학습 게임은 다운로드 파일에서도 실제로 실행됩니다. 새 자료 제작에 필요한 현재 프롬프트와 전달 조건은 `docs/RESULT_PROMPTS.md`에 있습니다.

## QR·화면 맞춤 수정

- 화면에 방 식별자나 입력창을 표시하지 않습니다. QR에 필요한 내부 연결값은 기존 행사와 설정을 유지합니다.
- 시작 화면·입장 화면·관리자 화면의 QR을 클릭하면 크게 열립니다. ESC 또는 닫기로 복귀합니다.
- 투표 초기화는 QR 바로 아래에 있습니다. 초기화 시 확인창을 거칩니다.
- 프로젝터는 고정 1600×900 화면을 사용하며 실제 표시 영역에 맞춰 전체를 축소합니다. 투표의 6개 항목을 같은 화면에 유지합니다.
- 5번 결과 발표는 3·2·1 후 선정 업무를 표시합니다. 별도의 음성 자막 상자는 표시하지 않습니다. 음성을 켠 상태에서 자동 재생하며 ‘결과 발표 음성’ 버튼으로 직접 재생할 수도 있습니다.
- 6번 프롬프트 제목은 두 줄로 고정합니다. 각 문구 안에서는 줄바꿈하지 않습니다.
- 7·8번 단계도 다음 버튼을 눌러 건너뛸 수 있습니다. 다음 단계로 이동하면 재생 중 음성을 중지합니다.

최종 빌드와 자동화 테스트 33개를 확인했습니다. 창 크기별 16:9 계산, QR 확대·초기화 위치, 결과 발표 표시, 연출 건너뛰기, 음성 중단을 검증했습니다. 실제 노트북의 렌더링·한국어/일본어 음성은 현장에서 확인해야 합니다.
