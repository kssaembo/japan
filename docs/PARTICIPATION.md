# 고정방 참여 안내

## 이번 변경

- 등장과 입장 화면을 하나로 합쳤습니다. 중앙 캐릭터, 오른쪽 안내, 하단 큰 참여 인원을 표시합니다.
- ‘QR 보기’는 보조 기능입니다. 링크로 들어온 청중이 다시 QR을 찍을 필요는 없습니다.
- 청중은 참여 페이지에 들어오면 익명 입장 기록을 저장합니다. 투표 시작 전에는 ‘참여 완료 / 투표 시작을 기다려 주세요’가 표시됩니다.
- 강사가 ‘투표 시작’을 누르면 대기 화면이 선택 화면으로 전환됩니다. 상태 확인 간격은 2.5초입니다.
- 화면에는 총 9개 장면을 표시합니다. 기존 서버의 단계 번호는 보존하므로 새 SQL 적용은 필요하지 않습니다.

## 슬라이드에 연결할 주소

1. 재배포 후 관리자 화면의 기존 고정방을 엽니다.
2. ‘참여 링크 복사’를 누릅니다. 이 주소를 강의 슬라이드 버튼에 붙여 넣으면 바로 참여합니다.
3. 짧은 주소 `https://japan-chi-hazel.vercel.app/vote`를 쓰려면 Vercel 환경변수 `VITE_EVENT_CODE`에 기존 방 식별자를 설정하고 재배포합니다. 식별자는 청중 화면에 표시하지 않습니다. 이미 설정했다면 변경할 필요 없습니다.
4. 이 환경변수가 없다면 복사 버튼은 기존 방의 `/vote/내부식별자` 주소를 복사합니다. 이 주소도 계속 고정해서 사용할 수 있습니다. 새 방은 만들지 마세요.
5. 강의 슬라이드 서비스는 이번에 수정하지 않았습니다. 다음 작업에서 그 버튼만 위 참여 주소로 연결하면 됩니다.

## 참여 인원과 초기화

참여 인원은 해당 방에 입장 기록을 저장한 익명 브라우저의 누적 수입니다. 현재 접속 중인 인원이나 투표 수와 다릅니다. 같은 브라우저의 같은 익명 ID로 새로고침하면 다시 세지 않습니다. 다른 브라우저·시크릿 창·저장 데이터 삭제는 별도 참여로 셀 수 있습니다.

투표 초기화는 투표 회차와 득표를 초기화하며 누적 입장 인원은 유지합니다. 기존 방에 이전 입장 기록이 있다면 숫자가 0에서 시작하지 않을 수 있습니다.

## 배포 후 확인

- 노트북에서 기존 방의 통합 시작 화면을 띄웁니다.
- 스마트폰에서 복사한 참여 주소에 접속합니다. 참여 완료 안내와 인원 증가를 확인합니다.
- 스마트폰을 새로고침해 중복 집계되지 않는지 확인합니다.
- 강사가 투표 시작을 누릅니다. 스마트폰이 선택 화면으로 바뀌고 실제 표가 반영되는지 확인합니다.
- QR 보기와 확대, 투표 초기화, 관리자 복귀도 확인합니다.

자동화 UI 테스트 35개와 빌드를 확인했습니다. 실제 Supabase 연결, 다중 기기, 프로젝터, 대규모 동시 접속은 현장 테스트가 별도로 필요합니다.
