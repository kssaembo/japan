# 한국어·일본어 사전 음성 제작 안내

이 프로젝트에는 실제 MP3 음성이 포함되어 있지 않습니다. 음성 대본과 재생 경로만 준비되어 있습니다. 대본은 `scripts.csv`, 앱의 기준 데이터는 `src/content/audio.ts`입니다. 총 66개 파일(한국어 33개, 일본어 33개)을 제작하면 전체 기본 음성을 사용할 수 있습니다.

## 제작 절차

1. `scripts.csv`의 언어와 실제 읽을 문장을 기준으로 사람의 녹음 또는 사용 권한이 있는 음성 제작 도구로 사전 제작합니다. 웹서비스 실행 중 TTS API를 호출하지 않습니다.
2. 일본어는 일본어 화자가 검수합니다. 억지로 한국어 어순을 따라 읽지 않습니다. AI는 한국어에서 에이아이, 일본어에서 エーアイ로 읽습니다.
3. 친근한 성인 교사의 목소리로 녹음합니다. 유머의 반전 전에 짧게 쉬되, 긴 무음과 과도한 웃음은 피합니다. 예상 길이는 제작 참고치이며 실제 음성의 길이를 보장하지 않습니다.
4. MP3, 44.1 kHz 또는 48 kHz, 128~192 kbps를 권장합니다. 문장 앞뒤 불필요한 무음을 줄이고 앞 음절을 자르지 않습니다. 두 언어의 체감 음량을 일치시킵니다. 실제 강의장 스피커에서 너무 크거나 작은 파일이 없는지 확인합니다.
5. CSV의 `/audio/ko/intro.mp3`는 프로젝트의 `public/audio/ko/intro.mp3`에 넣습니다. 일본어는 `public/audio/ja/intro.mp3`입니다. 파일명은 변경하지 않습니다. 파일을 추가한 다음 다시 빌드·배포하면 코드 변경 없이 같은 경로로 읽습니다.
6. 파일 확장자만 MP3로 바꾼 가짜 파일을 넣지 않습니다. 모든 파일을 실제 재생하여 손상·잘림·언어 오류를 점검합니다.

## 파일 구성

- 공통: intro.mp3, prompt_send.mp3, result_intro.mp3
- 선정 발표: winner_lesson.mp3, winner_homework.mp3, winner_game.mp3, winner_letter.mp3, winner_meeting.mp3, winner_speaking.mp3
- 위트 멘트: lesson_01~04.mp3, homework_01~04.mp3, game_01~04.mp3, letter_01~04.mp3, meeting_01~04.mp3, speaking_01~04.mp3
- 각 파일을 ko와 ja 폴더에 각각 준비합니다.

## 현장 점검

강사 화면에서 오디오를 활성화하고 실제 스피커로 테스트합니다. 브라우저 자동재생 허용을 전제로 하지 않습니다. 한국어→일본어 순차 재생은 첫 파일의 종료를 기준으로 다음 파일을 재생해야 합니다. 언어가 바뀌면 같은 언어의 자막을 보여 줍니다. 파일이 없거나 재생에 실패해도 자막으로 진행할 수 있어야 합니다. 자막의 세밀한 단어별 타이밍은 대본의 예상 길이만으로 정확히 맞출 수 없으므로, 문장 단위 자막과 실제 음성 재생 이벤트를 기준으로 확인합니다.

사전 캐시 후 오프라인 리허설에서도 음성이 나오는지 확인합니다. 파일을 교체하면 캐시를 갱신하고 다시 점검합니다. 학생 스마트폰에는 자동 음성을 재생하지 않습니다. 음성 라이선스가 공개 행사 재생과 웹사이트 배포를 허용하는지 확인합니다.
