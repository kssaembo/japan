## 출국 전

- [ ] Supabase SQL 실행, 강사 계정·관리자 UUID 등록, 공개 회원가입 해제
- [ ] 공개 배포 주소에서 로그아웃 상태 청중 투표 페이지 접근 확인
- [ ] 다른 네트워크의 PC와 스마트폰으로 실제 1표 저장 및 집계 확인
- [ ] 같은 스마트폰에서 새로고침·중복 누름 후 표가 증가하지 않음
- [ ] 투표 마감 후 신규 표가 추가되지 않음
- [ ] 전송 실패 → 재전송 시 중복 표 없이 기존 결과 확인
- [ ] `npm run test:live` 30/50/100명 동시 요청 및 재전송 통과
- [ ] 강사 페이지 새로고침·닫았다 재접속 후 동일 행사 복구
- [ ] 강사와 프로젝터가 같은 단계·확정 결과·자료 부분을 표시
- [ ] 전광판 네트워크 차단 → 마지막 확인값 유지 → 복구 후 DB 수치 일치
- [ ] Realtime 연결을 차단해도 2~3초 DB 재조회로 집계 복구
- [ ] 동점 발생 → 강사 선택 → 최다 득표 항목 중 하나만 확정 가능
- [ ] 실제 행사, 리허설 행사, 로컬 데모 기록이 분리됨
- [ ] 초기화 시 새 회차에서 재투표 가능, 이전 회차 지연 요청은 거절

## 음성

- [ ] 대본 66개 중 사용할 음성 전체 제작 및 파일명 일치
- [ ] 한국어·일본어 현지 발음과 번역 검토
- [ ] 브라우저에서 전체 MP3 검사, 한국어·일본어 재생 테스트
- [ ] 두 언어 순차 재생, 음량, 중지, 다시 듣기 확인
- [ ] 음성 파일을 일부러 누락시켜도 자막과 수동 진행 정상
- [ ] 음성 재생 중 단계 건너뛰기·긴급 중지 시 이전 음성 중단
- [ ] 강사 탭만 소리 재생, 청중·프로젝터 탭 자동 소리 없음
- [ ] 운영 탭이 백그라운드일 때에도 실제 사용 브라우저에서 재생 정상
- [ ] PC 스피커/HDMI 출력 장치, 행사장 볼륨, 앞뒤 무음 확인

## 일본 현장

- [ ] 행사장 Wi-Fi와 일본 LTE/5G 각각 QR 접속 및 투표 확인
- [ ] iPhone Safari, Android Chrome 각각 투표·오류 재시도 확인
- [ ] 프로젝트가 사용 가능 상태이며 로그인·RPC 응답 정상
- [ ] 강사 노트북 Windows 화면 확장, 프로젝터 F11 전체 화면
- [ ] 16:9 화면에서 후열의 글자·득표수·QR 인식 확인
- [ ] 24종 자료 중 공개 예정 자료의 표·일본어·게임 확인
- [ ] MP3와 앱 오프라인 캐시 완료 후 비행기 모드에서 데모 진행
- [ ] 실제 서버 장애 시 관객에게 알리고 데모 프로젝터로 전환 연습
- [ ] 실연수용 새 행사 생성, 리허설 코드·가상 투표가 아닌지 확인
- [ ] 5~7분 전체 리허설, 일반 강의 슬라이드로 마지막 창 전환
