# 사용자 제작 결과물 적용

6개 업무의 대표 결과물(_01)을 제공된 파일로 연결했습니다. 결과 공개 단계와 `/materials` 자료 확인 페이지에서 동일한 자료를 사용합니다.

| 업무 | 실제 결과물 | 다운로드 |
|---|---|---|
| 수업 준비 | 활동지, 정답지, 프로젝터 미리보기 | PDF |
| 숙제 관리 | 일주일 미션 체크, 미션표, 교사용 자료 | PDF, HTML |
| 학습 게임 | 한국어 OX 도전 5문항 | 독립 실행 HTML |
| 가정통신문 | 한일 병기 추석 안내문, 교사용 확인 | PDF, 편집용 HTML |
| 회의 단축 | 체크 회의표, 회의 운영안, 확인 자료 | PDF, Word, HTML |
| 한국어 말하기 | 25초 영상, 4개 상황극 화면, 역할극 카드 | MP4, PDF 2종, HTML |

## 실행

1. `/materials`에서 업무를 선택해 표지·실행 화면을 확인합니다.
2. ‘다운로드’ 메뉴에서 개별 파일 을 저장합니다.
3. 강의에서는 투표 결과를 확정하고 교육자료 공개 단계로 이동합니다.
4. 자료 탭을 누릅니다. 강사·프로젝터의 탭 선택은 행사에 저장되어 새로고침 후 복구됩니다. 영상은 자동 재생하지 않습니다.

PDF는 렌더링한 페이지 이미지로 미리보기하며 실제 원본 PDF를 다운로드합니다. HTML은 외부 AI 호출 없이 제공된 코드 그대로 실행합니다. 숙제와 회의의 삽입 화면은 격리되어 체크가 현재 화면에만 남을 수 있습니다. 새 탭에서 열면 브라우저 저장을 사용할 수 있습니다. 삽입 화면의 체크 초기화는 즉시 실행하며, 새 탭의 원본 화면은 확인창을 유지합니다. 

## 교체

실제 파일은 `public/materials/결과물ID/`에, 연결 정보는 `src/content/assets.ts`에 있습니다. 파일 교체 후 재배포하세요. Vercel에 환경변수를 다시 등록하거나 기존 투표 SQL을 변경할 필요는 없습니다. 투표용 서버와 관리자 인증은 유지합니다.

오프라인 준비 버튼은 영상·HTML·PDF·이미지까지 캐시합니다. 배포 후 온라인에서 먼저 준비하고 오프라인 리허설하세요. 실제 투표에는 인터넷이 필요합니다.

## 검증

자동화 테스트 27개 통과. 제공된 OX 게임의 5문항 정답 처리·5/5 점수·재시작, 숙제·회의 체크·초기화, 6개 업무의 파일 존재와 화면 연결을 확인했습니다. MP4는 H.264/AAC, 1280×720, 25.07초입니다. 실제 브라우저 렌더링·음성 출력·iPhone/Android·프로젝터·온라인 투표 연동은 현장 리허설에서 확인해야 합니다.

## 경량 파일 적용

표지 6개는 cover.webp를 사용합니다. 말하기 첫 화면은 slide-1.webp이며 나머지 상황극 화면은 기존 PNG입니다. 전체 다운로드용 ZIP을 제거하고 개별 PDF·HTML·Word·MP4 다운로드는 유지했습니다.
