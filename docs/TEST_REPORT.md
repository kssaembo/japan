# 개발 검증 기록

검증일: 2026-10-09. 이 기록은 개발환경에서 실제로 실행한 항목과 미실행 항목을 분리합니다.

## 실행 완료

| 검사 | 결과 | 범위 |
|---|---|---|
| TypeScript | 통과 | 전체 앱과 테스트 타입 검사 |
| Vite production build | 통과 | 정적 배포 번들 및 오프라인 캐시 목록 생성 |
| Vitest | 15개 통과 | 상태 전이, 동점, 결과물 중복 회피, 종료·초기화, 콘텐츠 무결성, DOM 상호작용 |
| DOM 강사 데모 | 통과 | 투표 시작, 표 증가, 마감, 1위, 결과 공개, 다시 렌더링 후 복구, 종료된 데모 전체 초기화 후 버전 복구 |
| DOM 청중 투표 | 통과 | 서버 응답 전 성공 표시 없음, 이중 클릭 1회 전송, 실패 후 같은 요청 ID 재시도, 기존 투표 복구 |
| 콘텐츠 렌더링 | 통과 | 24개 자료의 모든 섹션 렌더링, 퀴즈 정답·해설 클릭 |
| PGlite SQL | 33개 assertion 통과 | 실제 마이그레이션을 내장 PostgreSQL에서 실행. 100개 고유 표, 10회 중복 재시도, 원본 선택 유지, 마감, 라운드 변경, 권한 거부 |
| Broadcast 장애 처리 | 통과 | 내장 DB에서 realtime.send를 오류 함수로 바꿔도 투표와 카운터 저장 유지 |
| 음성 파일 검사 | 미완성 자산 확인 | MP3 0/66개. 누락은 정상적으로 표시하며 가짜 파일을 생성하지 않음 |

PGlite 시험의 Auth와 Realtime 함수는 테스트용 대체 구현입니다. Supabase의 실제 JWT 검증·WebSocket·외부 네트워크·100개 동시 HTTP 요청을 검증한 결과가 아닙니다. DOM 시험은 jsdom을 사용하며 실제 브라우저의 화면 픽셀·오디오 디코딩을 검증하지 않습니다.

## 실행하지 못한 항목

- 사용자 소유 Supabase 프로젝트가 연결되지 않아 실제 Auth 로그인과 외부 RPC/Realtime 통합 시험 미실행
- 실제 서버 30/50/100명 동시 HTTP 투표 및 재전송 시험 미실행. `npm run test:live`로 실행 가능
- 실제 iPhone Safari·Android Chrome·일본 LTE/5G·서로 다른 Wi-Fi의 접속 시험 미실행
- MP3 파일이 없어 한국어·일본어 음질, 발음, 순차 재생, 브라우저 자동재생 차단 실측 미실행
- 사용 가능한 관리형 브라우저 검증 도구가 없어 실제 브라우저 스크린샷·16:9 프로젝터 가독성·오프라인 캐시 실측 미실행
- Vercel 사용자 계정 배포 미실행. 배포 설정과 절차 제공

현재 패키지는 코드·콘텐츠·DB 스키마와 로컬 검증을 갖춘 배포 준비본입니다. 실제 현장 운영 승인 판단은 `CHECKLIST.md`와 실제 서버 시험 결과를 기준으로 하세요.

## 알려진 동작 범위

- 1기기 1표는 브라우저 저장소의 무작위 UUID에 기반합니다. 다른 브라우저 또는 저장소 초기화까지 방지하는 신원 인증은 없습니다.
- 누적 입장과 최근 접속은 투표 수와 다릅니다. 최근 접속은 45초 heartbeat 기준입니다.
- public Broadcast는 알림 신호만 사용합니다. 클라이언트가 같은 채널에 허위 신호를 보내도 집계·단계는 DB 조회 결과만 반영합니다.
- 현재 단계·선정 업무·프롬프트·결과물·자료 페이지는 서버에 복구됩니다. 게임의 문항 진행과 정답 선택은 각 화면의 일시 상태입니다.
- 자막은 음성 시작 시각과 길이에 맞춘 문자 표시입니다. 정밀한 낱말별 타임코드 싱크는 제공하지 않습니다.
- 데모 탭 간 공유는 같은 브라우저·같은 오리진의 저장소를 사용합니다. 데모로 여러 스마트폰의 실제 투표를 흉내 내지 않습니다.
- 코드 안에 MP3는 없으며 전체 검사 시 누락 경고가 납니다. 음성이 없어도 텍스트 시연은 가능합니다.
